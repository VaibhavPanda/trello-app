# Trello Clone

A task management application built with React and Firebase. Users can authenticate with Google, create boards, manage lists and cards, mark cards as completed, and drag cards between lists.

## Features

- Google Authentication
- Create, edit and delete boards
- Create, edit and delete lists
- Create, edit and delete cards
- Mark cards as completed
- Drag and drop cards
- Reorder cards within lists
- Move cards between lists
- Responsive UI

## Tech Stack

- React
- React Router
- React Context API
- dnd-kit
- Plain CSS
- Firebase Authentication
- Firestore
- Firebase Hosting
